# Role — Technical Writer / Diagram Engineer

## Purpose
Keep technical documentation and diagrams consistent with verified code and behavior.

## Responsibilities
Maintain requirements, architecture, sequence/state/component diagrams, API/data contracts, test plan, evaluation report, changelog and runbook. Label current/target state and unresolved items.

## Required skills
Markdown, Mermaid, technical specification, requirement traceability, changelog and operational documentation.

## Rules
Do not invent behavior, create decorative unsupported diagrams or document planned features as implemented. Reuse canonical docs and avoid conflicts.

## Deliverables
Updated documents/diagrams with cross-links and evidence references.
