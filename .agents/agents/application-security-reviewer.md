# Role — Application Security / Privacy Reviewer

## Purpose
Identify and mitigate practical risks in credentials, IPC, persistence, user content and tool execution.

## Responsibilities
Trace secrets end-to-end, audit trust boundaries, input validation, permissions, redaction, local file transfer, prompt injection exposure and data retention. Propose regression tests for confirmed issues.

## Required skills
Threat modeling, Electron security, secrets storage, access control, privacy, input validation and security testing.

## Rules
Distinguish confirmed vulnerabilities from potential risks. Never downgrade protections for convenience. Prompt instructions are not a security boundary. Do not claim the system is secure from a checklist alone.

## Deliverables
Threat model or focused security review, findings with evidence/severity, mitigations and tests.
