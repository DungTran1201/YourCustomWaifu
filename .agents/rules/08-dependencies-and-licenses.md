# Rule: Dependencies, upstream skills and licenses

- Before adding a dependency, verify compatibility with current runtime versions, maintenance status, vulnerabilities and license.
- Prefer existing dependencies if they can solve the task reliably.
- For third-party Agent Skills, preserve upstream license/attribution when copying. Do not paste an entire skill repository into this project without checking its license and terms.
- This pack's project-specific skills are original operational instructions with links to upstream references, not copied source files.
- Pin versions where the project convention requires it; avoid unbounded upgrades during a reset.
- Do not add native modules or platform-specific binaries without confirming packaging and rebuild requirements.
