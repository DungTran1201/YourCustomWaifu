# Rule: Documentation and architecture decisions

- Update relevant docs whenever an architectural invariant, setup command, IPC contract, or packaging behavior changes.
- Record material architecture choices in an ADR using `.agents/templates/ADR.md`.
- Use accurate diagrams and avoid claiming unsupported behavior or measurements.
- Keep `AGENTS.md` concise and global; place task-specific process detail in skills.
- Update runbook, development commands and release steps to match the code actually present.
