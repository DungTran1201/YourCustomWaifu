# Rule: Desktop UX and accessibility

- Use a dark black/graphite UI with restrained white highlights and subtle gradients; avoid large pure-white blocks.
- Keep Chatspace text-focused and free of anime/avatar art.
- Use consistent tokens, typography, spacing, focus rings, hover/disabled/loading states and accessible contrast.
- All interactive controls need labels, keyboard access and visible focus; icon-only actions need accessible names/tooltips.
- Show confirmation for destructive actions and progress for expensive tasks such as VRM import.
- Keep Stage chrome minimal; Stage toggles, click-through, pause/resume and open Workspace must be understandable.
- Do not use color alone to communicate connection, error, paused or selected state.
